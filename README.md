# Kalmar Troubleshooting Intelligence — Android

Offline Android wrapper for the Kalmar DRU450 / DCU80–100 troubleshooting platform.

The GitHub Actions workflow reconstructs the prepared Android project, builds an installable debug APK, and publishes it as a workflow artifact.

- Application ID: `com.geogva.kalmartroubleshooting`
- Version: `11.1`
- Minimum Android: 8.0 (API 26)
- Offline database and embedded visuals included
